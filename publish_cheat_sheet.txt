From Project Folder
===================
cd Projects/gex
git add .
git commit -m "ready for v1.3.5"
git push
git tag -a v1.3.5 -m "Release v1.3.5"
git push origin v1.3.5

From Github
===========
Project will still be under the active 1.3 branch
Create a new release based on 1.3.5 tag
OR USE COMMAND LINE
gh release create v1.3.5 --title "Release v1.3.5" --notes "Release v1.3.5 notes..."

From Homebrew Folder
====================
cd /opt/homebrew/Library/Taps/ki-aura/homebrew-gex
curl -L -o v1.3.5.tar.gz https://github.com/ki-aura/gex/archive/refs/tags/v1.3.5.tar.gz
shasum -a 256 v1.3.5.tar.gz
rm *.gz
nano Formula/gex.rb
git add Formula/gex.rb
git commit -m "ready for v1.3.5"
git push

Test
====
brew update && brew install gex
gex -h
